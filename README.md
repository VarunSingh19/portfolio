# Varun Singh - Portfolio

A modern, responsive portfolio website built with Next.js, TypeScript, and MongoDB. Showcasing my journey as a Full-Stack Developer with hands-on experience in React, Next.js, Node.js, and MongoDB.

## 🚀 Features

- **Modern Tech Stack**: Built with Next.js 14, TypeScript, and Tailwind CSS
- **Blog System**: Integrated blog with rich text editor and image uploads
- **Authentication**: Secure login system using NextAuth
- **Database**: MongoDB with Prisma ORM
- **Responsive Design**: Mobile-first approach with dark/light mode
- **Performance Optimized**: Fast loading with SSR and static generation
- **Contact Form**: Email integration with Resend API

## 🛠️ Technologies Used

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB
- **Authentication**: NextAuth.js
- **Database**: MongoDB with Prisma
- **Styling**: Tailwind CSS, Radix UI, Magic UI
- **Deployment**: Vercel
- **Email**: Resend API
- **Image Storage**: Cloudinary
